# Pruebas Funcionales - Visor Rick and Morty

## Caso 1: Carga de personajes
**Pasos:** Abrir la aplicación  
**Resultado esperado:** Se muestran personajes en pantalla

## Caso 2: Like a personaje
**Pasos:** Click en botón Like  
**Resultado esperado:** El puntaje aumenta en 1

## Caso 3: Dislike a personaje
**Pasos:** Click en botón Dislike  
**Resultado esperado:** El puntaje disminuye en 1

## Caso 4: Persistencia de votos
**Pasos:** Dar Like y recargar la página  
**Resultado esperado:** El puntaje se mantiene

## Caso 5: Error de API
**Pasos:** Simular fallo de API  
**Resultado esperado:** Se muestra mensaje de error
